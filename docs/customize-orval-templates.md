# 自定义 Orval 代码生成模板

如果你想自定义 Orval 生成的代码格式，可以使用自定义模板功能。

## ⚠️ 注意

自定义模板比较复杂，通常不建议这样做，因为：

- 生成的代码不需要人工阅读
- 维护自定义模板需要额外工作
- 每次 Orval 升级可能需要更新模板

## 📝 如何自定义

### 1. 创建自定义模板文件

```bash
mkdir -p orval-templates
```

创建 `orval-templates/query.hbs`（Handlebars 模板）：

\`\`\`handlebars
{{#each operations}}
export const {{operationName}} = (
{{#each params}}
{{name}}{{#if optional}}?{{/if}}: {{type}},
{{/each}}
signal?: AbortSignal
) => {
return customInstance<{{returnType}}>({
url: \`{{path}}\`,
method: '{{method}}',
{{#if hasBody}}
data: {{bodyParamName}},
{{/if}}
signal,
})
}
{{/each}}
\`\`\`

### 2. 更新 orval.config.ts

\`\`\`typescript
export default defineConfig({
api: {
input: {
target: 'http://localhost:8089/schema/openapi.json',
},
output: {
target: './src/api/generated/api.ts',
client: 'react-query',
override: {
// 使用自定义模板
operations: {
template: './orval-templates/query.hbs',
},
},
},
},
})
\`\`\`

## 📚 模板变量

Orval 提供的常用变量：

- `{{operationName}}` - 函数名
- `{{path}}` - API 路径
- `{{method}}` - HTTP 方法
- `{{params}}` - 参数列表
- `{{returnType}}` - 返回类型

详细文档：https://orval.dev/guides/custom-client

## 🎯 替代方案（推荐）

### 使用 ESLint/Prettier 忽略生成的文件

在 `.eslintignore` 和 `.prettierignore` 中添加：

\`\`\`
src/api/generated/\*\*
\`\`\`

这样工具就不会对生成的代码进行检查或格式化。

### 折叠生成的文件

在 IDE 中折叠 `src/api/generated/` 目录，不需要查看这些文件。

### 使用注释说明

在生成的文件顶部已经有注释：

\`\`\`typescript
/\*\*

- Generated by Orval
- Do not edit manually.
  \*/
  \`\`\`

这告诉团队成员这是自动生成的代码。
