# API Client

OpenAPI client powered by **Orval** + **TanStack Query**.

## 📂 Directory Structure

```
src/api/
├── generated/          # Auto-generated by Orval (excluded from git)
│   ├── endpoints.ts    # React Query hooks
│   └── model.ts        # TypeScript types
├── axios-instance.ts   # Custom Axios configuration
├── query-client.ts     # TanStack Query setup
├── index.ts            # Unified exports
└── README.md           # This file
```

## 🚀 Quick Start

### 1. Generate API Client

Make sure your Litestar backend is running at `http://localhost:8089`

```bash
# Generate once
bun run generate:api

# Watch mode (auto-regenerate on changes)
bun run generate:api:watch
```

### 2. Use in Components

```tsx
import { useGetUsers, useCreateUser } from '@/api';

function MyComponent() {
  // Query
  const { data, isLoading } = useGetUsers();

  // Mutation
  const createMutation = useCreateUser();

  return (
    <div>
      {data?.map(user => (
        <div key={user.id}>{user.name}</div>
      ))}
    </div>
  );
}
```

## 🔧 Configuration

- **OpenAPI Source**: `http://localhost:8089/schema/openapi.json`
- **Orval Config**: `orval.config.ts` (project root)
- **Vite Proxy**: Configured in `vite.config.ts` for `/api` routes

## 🎯 Features

✅ **Type-safe** - End-to-end TypeScript types from backend to frontend
✅ **Auto-generated** - No manual API code writing
✅ **TanStack Query** - Built-in caching, refetching, and state management
✅ **DevTools** - React Query DevTools for debugging
✅ **Flexible** - Integrates with existing `apiConfigStore`

## 🔗 Related Files

- **Query Provider**: `src/main.tsx` (QueryClientProvider setup)
- **API Config Store**: `src/stores/apiConfigStore.ts` (baseURL, API key, etc.)
- **Vite Config**: `vite.config.ts` (API proxy for development)

## ⚠️ Important Notes

- The `generated/` directory is auto-generated and should not be manually edited
- Run `bun run generate:api` after backend API changes
- Generated files are excluded from git (see `.gitignore`)
